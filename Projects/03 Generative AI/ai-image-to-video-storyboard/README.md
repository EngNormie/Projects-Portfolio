# AI-Powered Image-to-Video Storyboard Generator

This project generates AI-created images from a sequence of prompts and assembles them into a short video.

## 🔧 Tools Used
- ComfyUI / Stable Diffusion (simulated here)
- Python (scripts for generation and video assembly)
- `moviepy` (for video creation)
- `ffmpeg` (optional, backend used by moviepy)
